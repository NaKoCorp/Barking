## How to sign

Open a pull request. A bot asks you to post this comment:

> I have read the CLA Document and I hereby sign the CLA

Your GitHub account name, the pull request and the date are then recorded in
the `signatures/cla.json` file of the `cla-signatures` branch of the
repository, which is public.
